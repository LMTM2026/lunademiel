LUNA DE MIEL · APP DEL VIAJE
=============================
Archivos para subir a GitHub: index.html, manifest.webmanifest, sw.js, firestore.rules y los .png
NO subas datos-iniciales.json (tiene los datos del viaje; el repositorio es público).

1) Firebase (console.firebase.google.com)
   - Crear proyecto (ej. "lmtm-lunademiel"). Analytics: no hace falta.
   - Agregar app web (ícono </>) → copiar el bloque firebaseConfig.
   - Pegarlo en index.html donde dice FIREBASE_CONFIG (reemplazar los PEGAR_AQUI).
   - Authentication → Comenzar → Correo electrónico/contraseña → Habilitar.
   - Authentication → Usuarios → Agregar usuario:  lmtm@lmtm.app   clave: LMTM 2026
   - Firestore Database → Crear base de datos → modo producción → región southamerica-east1.
   - Firestore → Reglas → pegar el contenido de firestore.rules → Publicar.

2) GitHub
   - Nuevo repositorio (ej. "lunademiel"), subir los archivos.
   - Settings → Pages → Branch: main / (root) → Save.
   - Queda en https://<usuario>.github.io/lunademiel/

3) Firebase de nuevo
   - Authentication → Settings → Dominios autorizados → agregar <usuario>.github.io

4) Primera vez
   - Abrir la app, entrar con usuario LMTM y clave LMTM 2026.
   - Resumen → ⚙️ Datos → Importar datos → elegir datos-iniciales.json.

5) Teléfono (Mario y Trini)
   - iPhone: Safari → Compartir → Agregar a pantalla de inicio.
   - Android: Chrome → ⋮ → Instalar app / Agregar a pantalla principal.
   - Entrar una vez con internet. Después abre y se puede editar sin señal;
     los cambios se sincronizan solos al volver la conexión.
